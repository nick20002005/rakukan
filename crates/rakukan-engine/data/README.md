# 英単語の復元リスト

`latin_scowl.txt` は SCOWL 2020.12.07 の english-words / american-words
のレベル10・20・35から、小文字ASCII英字のみの行を抽出し、重複除去・ソートしたものです。
出典と著作権・許諾文はルートの `NOTICE` に掲載しています。

`latin_extra.txt` はサービス名・開発ツール・AI・ゲーム・PC関連の独自補助リストです。
両ファイルはDLLへ埋め込みます。Meltypeのソース・辞書は使用していません。

ユーザー辞書 `user_dict.toml` と同じディレクトリに `latin_words.txt` を置くと、
1行1語で追加できます。UTF-8、小文字ASCII英字のみ、3文字以上を指定してください。
このファイルの語はローマ字として日本語に読める場合も復元対象です。
リストはプロセス内で初回照合時に一度だけ読み込みます。変更後はengineの再起動が必要です。
ファイルがない場合は無視し、読めない場合は警告ログを出して標準リストを使います。

標準リストでは、実際のローマ字変換器でASCIIが残らず、未確定文字が空または単独の
`n` となる語を除外します。打鍵ログのエントリ境界から最長一致し、後続が助詞または
「する」の活用、あるいは前置きのある文末の場合に復元します。読み全体が単独の
英単語の場合は従来どおり復元しません。読みとログが不一致、切り離されたログ、
ローマ字以外を含む区間には適用しません。辞書にない造語は既存の先頭限定処理に任せます。

一般英単語は先頭または助詞の直後に限って開始します。未知語 `seedream` 内の
`dream` だけを復元する誤検出を防ぐためです。補助リストとユーザー指定語はこの
開始位置制限を設けず、日本語の前置きに助詞がない場合も照合します。

既知の未解決事項: `python` + `no` は既存ローマ字変換器で `nn` が一つの
ログエントリへ合流し、`pyてょんお` となります。単語末尾のエントリ境界がないので
復元しません。`python` + `de` は復元できます。
学習キーは呼び出し元の元の読みを使うため、復元した読みと一致しない経路があります。
学習処理は変更していません。
